# Data Structure Project

This project implements various data structures including warehouse management system.

## Project Structure

- **Module1-4**: Different data structure implementations
- **Common**: Common utilities and definitions
- **warehouse**: Warehouse data processing and management
- **warehouse_data.csv**: Sample data for warehouse operations

## Building and Running

### Prerequisites
- C++ compiler (GCC, Clang, or MSVC)
- Make or CMake (optional)

### Compilation
```bash
g++ -o warehouse main.cpp Module1.cpp Module2.cpp Module3.cpp Module4.cpp
```

### Running
```bash
./warehouse
```

## Features

- Data structure implementations
- Warehouse management system
- CSV data processing
